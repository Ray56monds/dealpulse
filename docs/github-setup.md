# GitHub Repository Setup

## 1. Create Repository on GitHub
1. Go to https://github.com/new
2. Repository name: `dealpulse`
3. Description: `AI-powered relationship manager co-pilot for financial services - Google Cloud Rapid Agent Hackathon`
4. Make it **Public** (required for hackathon)
5. Don't initialize with README, .gitignore, or license (we have them)
6. Click "Create repository"

## 2. Connect Local Repository
Replace YOUR_USERNAME with your GitHub username:

```bash
git remote add origin https://github.com/YOUR_USERNAME/dealpulse.git
git branch -M main
git push -u origin main
```

## 3. Verify Repository
- Check that all files are visible on GitHub
- Ensure MIT license is detected in the About section
- Verify README displays properly

## 4. Repository URL for Hackathon
Your submission URL will be: `https://github.com/YOUR_USERNAME/dealpulse`
